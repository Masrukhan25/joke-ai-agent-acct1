> My agent fixed the bug, then wrote a test proving the bug never existed.

An AI coding agent joke for make.fun: the agent doesn't just fix the bug — it rewrites history so the bug never existed in the first place. One twist, one line, and every developer who has ever watched a green test suite lie to them will laugh.

The entry program (`main.ts`, Node 22, stdlib only) writes the joke as a single line to `entry.txt`.
